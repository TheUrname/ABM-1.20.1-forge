A port of the classic ABM (Armor Blades and More) mod to Minecraft 1.20.1 Forge.
This is an unofficial 1.20.1 port of the classic 1.7.10 mod "Anime Battle Mod" (Author: Alex). 

Developed entirely by myself, my sole intention was to play this mod on a higher version of Minecraft, but I couldn't find any existing ports, so I decided to develop it myself. Based on my understanding, the version I used to play was likely an unfinished version. Due to major changes in Minecraft's underlying architecture, there are many things I cannot accomplish with my current technical skills. I kindly ask for the understanding and patience of all the handsome guys and beautiful girls who play this mod.

## More Information About the Mod:
- Only ores and weapons have been ported. Almost all weapons are based on vanilla weapon mechanics.
- I do not plan to update this mod in the future.

## ⚠️ Disclaimer
1. **Original Author**: The copyrights of the original mod, its ideas, and art assets belong to the original author, **Alex**.
2. **Original Mod Status**: The original mod and its website (moditedgames.weebly.com) have ceased updates and are currently inaccessible.
3. **Purpose of this Repository**: This repository is for **technical exchange and learning purposes only**, providing the code porting implementation from 1.7.10 to 1.20.1 (rendering refactoring, registration system refactoring, etc.).
4. **Copyright Infringement Handling**: If the original author Alex sees this project and requests its removal, please contact me via GitHub Issue, and I will cooperate with the deletion immediately.

## Download & Installation
1. Go to the **Releases** page of this repository to download the latest `.jar` file.
2. Requires **Minecraft 1.20.1** and **Forge 47.4.10+**.
3. Place the `.jar` file into the game's `mods` folder and launch the game.
*(Note: The current version has removed armor, etc.)*
